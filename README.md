# Student Marks Calculator

## About the Project
This is my first Java project as a BCA student.
It calculates a student's total marks, percentage,
pass/fail result, and grade for five subjects.

## Features
- Takes the student's name as input.
- Accepts marks for five subjects.
- Calculates total marks out of 500.
- Calculates the percentage.
- Checks whether the student passed or failed.
- Assigns a grade based on the percentage.
- Validates marks between 0 and 100.

## Technologies Used
- Java
- Scanner class
- Arrays
- Loops
- If-else statements

## How to Run

### Step 1
Install Java JDK on your computer.

### Step 2
Open the terminal in the project folder.

### Step 3
Compile the program:

javac StudentMarksCalculator.java

### Step 4
Run the program:

java StudentMarksCalculator

## Grading System
- 90% and above: A+
- 80% to 89%: A
- 70% to 79%: B
- 60% to 69%: C
- 45% to 59%: D
- Below 45%: E
- If any subject has marks below 33, the result is Fail.
